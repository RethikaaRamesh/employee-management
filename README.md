🧑‍💼 Employee Management System

A web-based Employee Management System built using Flask, SQLite, HTML, CSS, and Python, designed to manage employee records efficiently with secure authentication and full CRUD operations.
This project demonstrates full-stack development, database handling, and deployment on cloud (Render).

🚀 Live Demo

🔗 Deployed Application:
https://employee-management-oona.onrender.com

🔗 GitHub Repository:
https://github.com/RethikaaRamesh/employee-management

🛠️ Tech Stack

Backend: Python, Flask

Frontend: HTML, CSS, Jinja2

Database: SQLite

Authentication: Password hashing (Werkzeug)

Version Control: Git & GitHub

Deployment: Render (Cloud Platform)

✨ Features

🔐 Secure Login & Logout (Password Hashing)

➕ Add New Employees

✏️ Update Employee Details

🗑️ Delete Employees

🔍 Search & Filter Employees

📊 Dashboard View

⚠️ Success & Error Flash Messages
